个人技术博客系统

Tailwind JavaScript Python MySQL

项目简介

本项目是一套前后端分离的个人技术博客系统，前端采用Tailwind CSS+原生JS实现响应式界面，后端基于Python Flask框架开发接口，数据库使用MySQL存储数据。系统支持文章发布、分类/标签管理、评论互动、全文搜索、用户登录等核心功能，界面简约清新，专注技术内容展示。

项目重点练习了前后端数据交互、RESTful API设计、数据库增删改查、前端表单验证与异步请求，最终实现了功能完整、体验流畅的个人技术博客解决方案。

项目亮点

  • 前后端分离架构，前端独立部署，后端提供纯接口服务，解耦性强
  • 支持Markdown编辑器发布文章，自动渲染代码高亮、公式等格式
  • 全文搜索功能，基于MySQL模糊查询+关键词权重排序，搜索精准
  • 评论区支持嵌套回复、表情互动，提升用户交流体验
  • 文章阅读量、点赞数统计，数据可视化展示博客运营情况
